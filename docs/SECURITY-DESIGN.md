# Trim 安全设计

## 范围与信任边界

Trim 是 Electron 主程序和 Tauri 安装器组成的 Windows 应用。渲染进程视为低信任边界：它只通过 `preload.js` 暴露的窄 IPC API 请求能力，不能直接访问 Node、文件系统、注册表或子进程。主进程和安装器是高权限边界，所有破坏性操作必须再次验证参数和当前状态。

## IPC 防护

- 高风险 IPC 验证 sender URL，只接受应用目录内的 `file://` 页面。
- 扫描类操作生成最近一次扫描快照；删除、修改和执行只接受快照中的 ID，并使用主进程保存的真实字段。
- 进程结束操作同时校验 PID 和扫描时的进程名，降低 PID 重用风险。
- 渲染进程不能登记任意后端 PID；只有主进程实际创建的子进程进入清理白名单。
- Electron 窗口拒绝非应用本地页面导航和重定向，只允许 `https:` 外链交给系统浏览器。

## 文件与重解析点

路径判断使用 canonical path，并对扫描根、扫描项和删除目标检查普通文件/目录及符号链接。配置、缓存、备份、历史和报告使用临时文件、flush/fsync 后原子替换，避免崩溃留下半个 JSON。

## API 密钥

API 密钥使用 Electron `safeStorage` 保存。Windows 上由系统凭据保护（通常基于 DPAPI）；配置文件仅保存带版本前缀的密文。安全存储不可用时拒绝写入明文。密钥不写入应用日志，也不随 AI 请求上传到非用户选择的服务。为保持体验，设置读取时会在本地解密供当前 UI 使用；生产 UI 应优先显示掩码，仅在编辑操作需要时读取。

## 安装与卸载

安装器写入 `.trim-install.json`，包含随机实例 ID、安装 scope、版本和相对文件清单，同时在卸载注册表项保存实例 ID 和 scope。卸载要求注册表信息与清单一致，只删除清单中的普通文件，保留用户后来放入的文件，并只删除空目录。运行中的程序仅在可执行文件路径位于目标安装目录内时结束。升级覆盖文件前写入临时回滚副本，失败时恢复。

## 内容安全策略与导航

Tauri WebView 使用 self-only 脚本策略，图片仅允许本地资源、`asset:` 和必要的 `data:`，网络连接限制为本地 IPC。Electron 窗口启用 context isolation、禁用 Node integration 和 sandbox，并通过 preload 提供受限接口。

## 威胁模型与验证

主要威胁包括被篡改的渲染输入、路径穿越、符号链接/重解析点、PID 重用、注册表备份失败后的误删、配置崩溃损坏、密钥明文泄露以及安装卸载误删用户文件。测试覆盖脚本生成、IPC 参数白名单、原子写入、密钥加解密、安装清单相对路径和 Rust 编译/单元测试。涉及注册表、系统清理和真实磁盘写入的测试必须使用 mock 或隔离测试机，不能在普通开发机直接执行破坏性流程。
