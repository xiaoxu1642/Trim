# Trim v2.0 界面重设计方案 —「碳墨 × 薰衣草」(Carbon & Lavender)

> 基于现有 v1.2 Fluent Design 体系的全面升级方案。参考基准：Linear（近黑画布 + 表面阶梯 + 薰衣草紫稀缺使用）、Raycast（深色 chrome + 发丝描边 + 语义色克制使用）、UI UX Pro Max（OLED 深色可读性规范）。
> 本文件供实现阶段直接引用，所有 token 均标注了与现有 `src/styles/main.css` 变量的映射关系。

---

## 1. 设计目标与方向

现有 v1.2 已具备良好基础（Mica、磨砂玻璃、MiSans 可变字体、深浅双主题），主要问题：

| 现状问题 | 影响 | 本方案对策 |
| --- | --- | --- |
| 背景 `#202020` 偏灰、无明度阶梯 | 层级靠阴影与透明度表达，卡片"浮"不起来 | 引入 4 级碳墨表面阶梯，层级靠表面明度 + 发丝描边 |
| 强调色 `#D3D4FA` 过浅，按钮/文本对比依赖深紫黑前景 | 品牌色可用场景窄 | 建立完整强调色阶：`#8B8EE0` 基色 + hover/press/soft/glow |
| 12 个页面平铺在侧边栏 | 认知负担重 | 按「清理 / 优化 / 管理 / 工具」分组导航 |
| 概览页 4 张等权卡片 | 缺决策焦点 | 新增「系统健康度」主卡（渐变圆环），一键清理/一键优化快捷入口 |
| 阴影 + 大圆角（14/18px）混合使用 | 质感不统一 | 统一 6–14px 圆角刻度，弱化投影，强调 1px 发丝描边 |

**一句话方向：** 把"工具感"升级为"精密仪器感"——更深的碳墨画布、更克制的紫色、更锐利的描边、更聚焦的信息层级。

### 2.4 圆角、间距、层级

| 项 | 值 |
| --- | --- |
| 圆角刻度 | 4（徽章/小标签）/ 6（输入、次级控件）/ 8（按钮）/ 10（普通卡片）/ 14（大卡/弹窗） |
| 间距 | 4px 网格：8/12/16/20/24/32；卡片内边距 16–20px |

| 描边 | 所有卡片/输入框/表格统一 1px 发丝描边 `--border-default` |

## 3. 组件规范

### 3.1 按钮
- **主按钮**：`--accent` 实底 + `--accent-text` 前景，8px 圆角，高 32–36px，hover 提亮至 `--accent-hover`，可按需加 `--accent-glow` 内阴影辉光；危险主操作（清理/删除）改 `--danger` 实底。
- **次按钮**：`--bg-surface-2` 底 + 1px 发丝描边，hover 升至 surface-3。
- **文字按钮/三态**：透明底，hover 加 `--bg-hover`。
- 统一 150–220ms 过渡，`--ease-standard`。

### 3.2 卡片
- `--bg-surface-1` + 1px 发丝描边 + 10px 圆角，padding 16–20px；hover 升 surface-2。
- 统计卡图标改为 36px 圆角方块内嵌渐变（延续现有 `--icon-bg` 机制），而非裸图标。
- 可点击卡片 hover 时增加 1px `--border-strong` 与轻微上浮 1px（无位移动画）。

### 3.3 侧边导航（信息架构改造）
- 宽 232px（可折叠至 56px），底色 surface-1 半透明。
- 分组结构（新增 `nav-section-title` 微标签）：
  - **清理**：系统概览 / 磁盘清理 / 内存清理 / 系统维护
  - **优化**：电脑优化中心（含分类子菜单）/ 启动项管理 / 右键管理（含分类子菜单）
  - **工具**：磁盘测速 / 网络测速 / 实时网速 / 快捷指令
  - **记录**：日志
  - 底部：设置 + 深浅主题切换
- 选中态：`--accent-soft` 圆角高亮块 + 左侧 3px `--accent` 指示条 + accent 图标文字；hover 态 surface-2。

### 3.4 徽章与状态
- 风险徽章：soft 底色 + 语义色文字 + 全圆角胶囊（`低风险`绿 / `中风险`黄 / `高风险`红 / `信息`蓝）。
- 进度条：6px 高圆角轨道，填充使用 `--accent` → `--accent-hover` 渐变 + 末端辉光；危险进度（如内存占用高）自动切换 `--warning`/`--danger` 色。

### 3.5 表格与列表
- 表头：`--fs-meta` 字号、`--fg-tertiary`、大写化、下描边 `--border-default`。
- 行分隔 1px `--border-subtle`；hover 行 surface-2；选中行 `--accent-soft`。

### 3.6 弹窗/浮层/Toast
- 弹窗：surface-3 + 发丝描边 + 大圆角 14px + 深投影；遮罩 `rgba(0,0,0,0.55)` + 8px 模糊。
- Toast：surface-3 + 左语义色 3px 条 + 图标，右上滑入。
- 空状态：居中图标（semantic 色 soft 圆底）+ 标题 + 描述 + 主按钮。

## 4. 布局与页面级改造

### 4.1 全局骨架
标题栏 36px（品牌名 + 原生控制按钮）→ 侧边栏 + 内容区；内容区统一 `page-header`（标题/副标题左侧，操作按钮右侧，主操作永远最右）。

### 4.2 系统概览（重点页）
- 顶部 4 卡：**健康度主卡**（渐变圆环 + 大数字 + "系统健康度" + 简短建议文案）+ 3 张资源卡（CPU / 内存 / 磁盘，各带进度条）。
- 新增**快捷操作条**：一键清理 / 一键优化 / 系统还原点 三个入口按钮（跳转对应页）。
- 硬件信息改为两栏紧凑表格（左标签右值，降低行高）。
- 卡片可点击跳转（内存→内存清理、磁盘→磁盘清理）保留并加 hover 提示。

### 4.3 磁盘清理 / 内存清理 / 优化中心
- 统一"统计卡 + 进度区 + 列表"三段式骨架。
- 清理项卡片：复选框 + 名称 + 描述 + 大小（右对齐、等宽数字）+ 风险徽章；高/中风险项徽章常显。
- 批量操作栏吸顶（sticky），执行中按钮转进度态（内嵌环形 spinner）。
- 优化中心分组卡片：标题 + 项数徽章 + 风险分布（绿/黄/红小圆点）+ 勾选；高危项卡片左侧加红色警示条。

### 4.4 启动项 / 右键管理
- 复用统一"扫描结果表格"组件：状态切换开关（Fluent toggle）、厂商列、描述列、操作列。
- 右键管理左侧分类筛选保留，改为胶囊筛选条（参照 Raycast pill-tab）。

### 4.5 测速 / 实时网速
- 结果数字统一大字号（24px/650）等宽展示；折线图沿用现有实现，但坐标轴/网格线改发丝描边色，图例用语义色。
- 磁盘测速参数区与结果区左右分栏，状态面板显示当前阶段（等待/测试中/完成）。

### 4.6 设置页
- 入口卡保持"一行三卡自适应均分"，卡片内加右箭头图标；弹窗统一样式升级（见 3.6）。
- 字体/主题预览区与主界面解耦的逻辑保留不变。

### 4.7 独立窗口（进程管理 / 大模型管理 / 图片预览）
- 沿用同一 token 体系（深色画布 + 表面阶梯），仅调整窗口尺寸与密度；进程树分组行保留展开箭头，箭头旋转动画保留。

### 4.8 玻璃皮肤与预设背景（保留并精修）
- `data-skin="glass"` 保留，但磨砂参数收敛：blur 26px → 18px、saturate 1.65 → 1.4，描边改用 `--border-strong`，避免"糊"。
- 预设背景（aurora/sunset/graphite）保留，透明度整体下调 15%，确保文字对比。
- Mica 材质检测逻辑（`body[data-material]`）保留。

## 5. 实现映射（CSS 变量对照）

| 新体系 | 现有变量 | 改动方式 |
| --- | --- | --- |
| `--bg-base` | `--bg-base` | 仅改值 `#202020 → #0F1115`（深）/ `#F3F3F3 → #F5F6F8`（浅） |
| surface 阶梯 | `--bg-card/-elevated/-input` | 重映射为阶梯值；新增 `--bg-surface-2` 别名 |
| `--accent` 族 | `--accent/-hover/-press/-light/-text` | 改值 + 新增 `--accent-soft`、`--accent-glow` |
| 语义色 soft | 新增 `--success-soft` 等 | 徽章/警示统一改用 soft 底 |
| 圆角 | `--radius-small/medium/large/xl` | 6/8/10/14 收紧 |
| 字号 | `--fs-page-title` 等 | 标题加负字距 |
| 阴影 | `--shadow-card` | 卡片改发丝描边，投影仅留 flyout/tooltip |

**实施顺序建议（P0 → P1）：**
1. **P0**：替换 CSS 变量值（几分钟内全界面换肤）+ 侧边栏分组重构
2. **P0**：概览页健康度主卡 + 快捷操作条
3. **P1**：按钮/卡片/徽章/进度条组件级精修（描边、圆角、hover）
4. **P1**：清理/优化/内存三页统一三段式骨架
5. **P1**：玻璃皮肤参数收敛、预设背景透明度下调
6. **P2**：表格、弹窗、Toast、独立窗口细节统一

## 6. 验收清单

- [ ] 深浅两主题下正文对比度均 ≥ 4.5:1（浅色 `#5E62C6` 已校验 5.9:1）
- [ ] 全部卡片有发丝描边、无过度投影；层级靠表面阶梯表达
- [ ] 侧边栏分组后 12 页均可 1 次点击到达（折叠态图标可辨识）
- [ ] 主按钮/危险按钮语义分离（紫=执行、红=删除/高危、绿=成功）
- [ ] 风险徽章三色（绿/黄/红）全页面口径一致
- [ ] 玻璃皮肤开启后文字仍满足对比度；Mica 关闭时降级正常
- [ ] 字体缩放（12–24px）与字重缩放（100–1000）滑块仍全局生效
- [ ] 键盘焦点可见（focus ring 用 `--accent` 2px）
- [ ] 动画遵守 `prefers-reduced-motion`（沿用现有 duration token）
