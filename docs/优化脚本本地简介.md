## 启动与响应（6 项）

> 启动与响应类：围绕开机速度、磁盘与文件系统、系统响应性进行调整，收益直接但部分项会影响休眠、快速启动等既有功能。

### BCD 超优化

- **标识**：`bcd_opt`（本地简介 key）

- **风险**：高风险

- **本地简介**：修改启动配置数据（BCD）关闭开机动画、调试与超时等待以缩短启动时间；属高风险项，务必先创建系统还原点。

### SSD 固态硬盘优化

- **标识**：`ssd_opt`（本地简介 key）

- **风险**：低风险

- **本地简介**：按固态硬盘特性关闭计划碎片整理、启用 TRIM 与正确的写入策略，延长固态寿命并保持读写速度。

### 核心响应性杂项

- **标识**：`tf_core_misc`（本地简介 key）

- **风险**：中风险

- **本地简介**：调整菜单延迟、关机等待、窗口动画等系统响应参数，让界面交互更跟手，属于低风险的体验优化。

### 关闭休眠与快速启动

- **标识**：`tf_hibern_off`（本地简介 key）

- **风险**：中风险

- **本地简介**：关闭休眠与快速启动并删除 hiberfil.sys，可释放数 GB 系统盘空间；代价是失去休眠功能与快速开机。

### NTFS 文件系统调优

- **标识**：`tf_ntfs`（本地简介 key）

- **风险**：中风险

- **本地简介**：关闭 8.3 短名、最后访问时间戳等 NTFS 元数据写入，减少无谓磁盘写入，机械硬盘上的收益更明显。

### 合并计时器与现代待机

- **标识**：`tf_timer_coal`（本地简介 key）

- **风险**：中风险

- **本地简介**：关闭计时器合并以提升计时精度与前台响应速度，代价是待机功耗上升，笔记本用户需权衡续航。

## 游戏与多媒体（10 项）

> 游戏与多媒体类：为游戏与影音场景分配更多系统资源、关闭后台录制与干扰项，代价通常是功耗上升或部分辅助功能被关闭。

### 禁用 UAC（用户账户控制）

- **标识**：`disable_uac`（本地简介 key）

- **风险**：高风险

- **本地简介**：完全关闭用户账户控制，不再弹出提权提示，代价是系统安全性显著下降，不建议日常使用。

### 关闭游戏 DVR 录制

- **标识**：`game_dvr`（本地简介 key）

- **风险**：低风险

- **本地简介**：关闭 Xbox 游戏栏的后台录制与广播，释放 GPU 与磁盘占用，避免帧率被后台录制拖低。

### MMCSS优化

- **标识**：`mmcss_optimize`（本地简介 key）

- **风险**：中风险

- **本地简介**：合并原「游戏高优先级」与「MMCSS 系统增强」：Games 任务高调度/高 GPU 优先级 + 低延迟标记 + 系统级 NoLazyMode/AlwaysOn，为游戏与影音提供低延迟的多媒体调度（原「启用 Games 低延迟调度标记」同值重复已并入）。

### 永劫无间 CPU 高优先级

- **标识**：`nara_prio`（本地简介 key）

- **风险**：低风险

- **本地简介**：为《永劫无间》进程设置 CPU 与 IO 优先级，减少后台抢占造成的帧率波动，对其他游戏无效。

### 全屏优化(FSO)行为

- **标识**：`tf_fso`（本地简介 key）

- **风险**：低风险

- **本地简介**：调整全屏优化（FSO）行为，为老游戏禁用或启用 FSO，以修复黑屏、Alt+Tab 卡顿与输入延迟问题。

### 关闭游戏栏后台捕获

- **标识**：`tf_gamebar`（本地简介 key）

- **风险**：低风险

- **本地简介**：关闭游戏栏的后台录制与截图捕获组件，减少资源占用，同时保留 Win+G 快捷键的可用入口。

### 开启游戏模式

- **标识**：`tf_gamemode`（本地简介 key）

- **风险**：低风险

- **本地简介**：开启 Windows 游戏模式，让系统在游戏运行时优先分配资源并抑制后台更新与通知。

### GPU 延迟容忍度调优

- **标识**：`tf_gpu_latency`（本地简介 key）

- **风险**：中风险

- **本地简介**：调整 GPU 延迟容忍度与抢占策略，降低 DPC 延迟与帧生成抖动，对竞技类游戏收益较明显。

### 进程 CPU/IO 优先级（IFEO PerfOptions）

- **标识**：`tf_ifeo_perf`（本地简介 key）

- **风险**：高风险

- **本地简介**：通过 IFEO 为指定进程固定 CPU/IO 与页面优先级；配置不当可能影响稳定性，属高风险项。

### 清空 IFEO 调试项

- **标识**：`tf_ifeo_wipe`（本地简介 key）

- **风险**：高风险

- **本地简介**：清理注册表中残留的 IFEO 调试器与优先级配置，恢复程序默认启动行为，用于修复被篡改的启动配置。

## 系统服务与内存（7 项）

> 系统服务与内存类：通过停用非必要服务与调整内存策略释放资源，范围越大风险越高，请逐项确认自己不依赖被禁用的服务。

### 禁用下载地图管理器

- **标识**：`maps_off`（本地简介 key）

- **风险**：低风险

- **本地简介**：关闭后台自动下载离线地图的服务，节省磁盘与带宽；需要使用系统地图应用时手动重新开启即可。

### 禁用内存压缩

- **标识**：`mem_compress`（本地简介 key）

- **风险**：中风险

- **本地简介**：关闭系统内存压缩，用更多内存占用换取 CPU 开销下降；8GB 及以下内存的机器不建议关闭。

### 禁用冗余后台服务

- **标识**：`services_off`（本地简介 key）

- **风险**：高风险

- **本地简介**：停用一批非必要的后台服务以释放内存与 CPU；禁用前请确认自己不依赖相关功能（如传真、远程注册表）。

### SVCHost 内存拆分阈值

- **标识**：`svc_mem_gb`（本地简介 key）

- **风险**：中风险

- **本地简介**：提高 SVCHost 进程拆分的内存阈值，减少进程数量与内存碎片，适合大内存机器。

### 禁用高风险驱动服务

- **标识**：`tf_drv_disable`（本地简介 key）

- **风险**：高风险

- **本地简介**：禁用部分易出问题或极少使用的驱动服务，降低攻击面与蓝屏概率；误禁用可能导致对应硬件不可用。

### 关闭内存压缩与页合并

- **标识**：`tf_mmagent`（本地简介 key）

- **风险**：中风险

- **本地简介**：关闭内存压缩与页面合并，降低后台 CPU 开销，代价是多任务场景下更容易吃满物理内存。

### 禁用 70+ 非必要服务

- **标识**：`tf_svc_bulk`（本地简介 key）

- **风险**：高风险

- **本地简介**：批量禁用 70 多个被认为非必要的服务以释放资源，范围较大，可能影响打印、蓝牙、远程桌面等功能，属高风险项。

## 安全与隐私（5 项）

> 安全与隐私类：关闭遥测、数据收集与部分防护功能以减少外发与后台活动；关闭安全防护类项目会显著降低系统安全性，请谨慎取舍。

### 禁用电源节能

- **标识**：`power_off`（本地简介 key）

- **风险**：中风险

- **本地简介**：关闭处理器节能与链接状态电源管理，换取持续高性能输出，代价是功耗、温度上升与笔记本续航缩短。

### 关闭默认共享

- **标识**：`share_off`（本地简介 key）

- **风险**：中风险

- **本地简介**：关闭 ADMIN$、C$ 等默认隐藏共享，减少局域网被横向访问的风险，仅影响远程管理类场景。

### 遥测优化

- **标识**：`telemetry_optimize`（本地简介 key）

- **风险**：中风险

- **本地简介**：合并原「关闭系统遥测」与「停用遥测计划任务/日志」：策略层 + 计划任务层 + AutoLogger + 遥测服务四层一体掐断遥测采集与上传，减少隐私外发与后台网络活动。

### 关闭 Defender 与 SmartScreen

- **标识**：`tf_defender`（本地简介 key）

- **风险**：高风险

- **本地简介**：关闭 Microsoft Defender 实时防护与 SmartScreen，会显著降低系统安全防护，仅在有替代杀软并明确接受风险时执行。

### 系统隐私设置

- **标识**：`tf_privacy`（本地简介 key）

- **风险**：中风险

- **本地简介**：统一关闭广告 ID、位置、活动历史等隐私选项，减少个性化数据收集，不影响系统功能的正常可用。

### 禁用 Cortana 与网页搜索

- **风险**：中风险

- **本地简介**：关闭 Cortana 与开始菜单的网页搜索，减少联网搜索与后台进程，不影响本地文件搜索。

### 彻底卸载 OneDrive

- **标识**：`tf_onedrive`（本地简介 key）

- **风险**：高风险

- **本地简介**：完整卸载 OneDrive 并清理资源管理器侧栏入口，释放磁盘与后台同步开销；正在使用云盘的用户请先完成同步备份。

### OOSU 隐私工具静默导入

- **标识**：`tf_oosu`（本地简介 key）

- **风险**：中风险

- **本地简介**：以静默方式导入 OOSU 类隐私配置模板，批量关闭遥测与数据收集项，配置内容公开可查。

### PCCleaner 深度清理

- **标识**：`tf_pccleaner`（本地简介 key）

- **风险**：中风险

- **本地简介**：执行更彻底的系统垃圾清理（含日志、缓存、更新残留），清理范围更大，建议先扫描确认再执行。

## 键鼠与外设（8 项）

> 键鼠与外设类：针对输入设备的延迟、加速与电源策略做调优，属于体感收益明显且多数可还原的项目。

### 鼠标优化

- **标识**：`mouse_optimize`（本地简介 key）

- **风险**：中风险

- **本地简介**：合并原「鼠标去加速 + 6/11 灵敏度」与「清空平滑鼠标曲线」：关闭指针加速、灵敏度固定 6/11 档并清零平滑曲线，指针移动完全线性，得到与多数 FPS 游戏一致的原始输入手感。

### 禁用高清音频控制器

- **标识**：`tf_dev_audio`（本地简介 key）

- **风险**：高风险

- **本地简介**：禁用主板高清音频控制器，仅在改用独立声卡或 USB 音频设备时使用，否则会导致无声。

### 禁用 24 个冗余板载设备

- **标识**：`tf_dev_disable`（本地简介 key）

- **风险**：高风险

- **本地简介**：批量禁用串口、并口等 24 个极少使用的板载设备，减少驱动占用与设备枚举开销，需要时请还原。

### 禁用打印队列设备

- **标识**：`tf_dev_printer`（本地简介 key）

- **风险**：高风险

- **本地简介**：禁用打印队列与相关设备，减少后台服务开销；仍需要打印的机器请勿执行。

### 键盘：零延迟 + 队列深度

- **标识**：`tf_keyboard`（本地简介 key）

- **风险**：低风险

- **本地简介**：调整键盘重复延迟与输入队列深度，缩短按键响应与连击间隔，提升打字与游戏跟手度。

### 彻底禁用粘滞/筛选/切换键

- **风险**：高风险

- **本地简介**：写入内核 MitigationOptions 二进制值关闭漏洞利用缓解（乱序内存等），可小幅提升内存分配性能，但显著降低防护，属高风险项。

### 关闭 Windows 全局通知横幅

- **标识**：`perf_notifications_off`（本地简介 key）

- **风险**：中风险

- **本地简介**：关闭系统全局通知横幅与提示音，减少打扰，重要的系统告警也可能一并被隐藏。

### 加快预读能力改善速度

- **标识**：`perf_prefetcher_fast`（本地简介 key）

- **风险**：低风险

- **本地简介**：EnablePrefetcher=3 同时启用应用与启动预读，改善程序启动与文件访问速度；SSD 上收益有限。

### 关闭远程协助

- **标识**：`perf_remote_assist_off`（本地简介 key）

- **风险**：低风险

- **本地简介**：禁用 Windows 远程协助的受邀协助入口，减少攻击面与后台监听。

### 缩短服务关闭等待时间

- **标识**：`perf_service_shutdown_fast`（本地简介 key）

- **风险**：低风险

- **本地简介**：WaitToKillServiceTimeout=2000，缩短关机时等待服务停止的超时，关机不再卡在「正在关闭」。

### 加快关机速度

- **标识**：`perf_shutdown_fast`（本地简介 key）

- **风险**：低风险

- **本地简介**：WaitToKillAppTimeout=2000，缩短系统等待应用退出的超时，让关机/注销更快。

### 商店应用自动更新排查

- **标识**：`perf_store_auto_update_off`（本地简介 key）

- **风险**：中风险

- **本地简介**：关闭 Microsoft Store 应用的自动更新，避免更新时机不可控；请记得定期手动更新以修复安全漏洞。

### UWP 后台运行排查

- **标识**：`perf_uwp_background_off`（本地简介 key）

- **风险**：中风险

- **本地简介**：排查并限制 UWP 应用的后台运行，减少后台唤醒与耗电，消息类应用可能延迟收到通知。

### 关闭 VBS / 内存完整性

- **标识**：`perf_vbs_off`（本地简介 key）

- **风险**：高风险

- **本地简介**：关闭基于虚拟化的安全（VBS）与内存完整性保护，可提升部分游戏性能，但会明显削弱系统对内核级攻击的防护。

### Windows 自动更新策略排查

- **标识**：`perf_windows_update_off`（本地简介 key）

- **风险**：中风险

- **本地简介**：排查并调整 Windows 自动更新策略，避免更新打断工作；长期关闭会带来安全风险，建议仅临时暂缓。

### 关闭 Windows AI 组件

- **标识**：`tf_ai_off`（本地简介 key）

- **风险**：低风险

- **本地简介**：通过系统策略关闭 Copilot、Recall、Click to Do、AI Agent 连接器及相关运行时服务，减少后台活动和 AI 数据处理。执行后这些 Windows AI 功能将不可用，但可用内置还原操作恢复。

### 系统响应微调合集

- **标识**：`tf_perf_misc`（本地简介 key）

- **风险**：低风险

- **本地简介**：取消开机启动延迟，并关闭窗口摇晃、失效快捷方式自动查找及运行/资源管理器自动建议，以减少等待与不必要的搜索。该项主要改变交互偏好，不会提升硬件性能。
