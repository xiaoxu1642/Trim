Trim NSIS 安装器美化方案

当前 electron-builder 产出的 NSIS 安装包走 MUI2 默认界面——蓝色横幅、灰白配色、无品牌识别。本方案在保留向导式功能（选目录 / 快捷方式 / 免 UAC）的前提下，通过品牌侧边图 + 顶部横幅 + 配色定制，把安装器对齐 Trim 的碳墨×薰衣草视觉语言。

electron-builder 26.15 NSIS MUI2 品牌色 #171832 / #8B8EE0 零新增依赖 向导式保留

现状与目标

当前 package.json 的 nsis 配置只声明了功能参数，没有任何视觉定制。

当前界面问题

① MUI2 默认蓝色顶部横幅（#0066CC 系），与 Trim 品牌色无关；② 欢迎页左侧 164px 区域纯白空白，浪费品牌展示位；③ 按钮是系统默认灰色，无主按钮强调；④ 整体观感像 2005 年的共享软件安装器，与 Trim 应用内的 Fluent Design 深色语言割裂。

美化目标

① 欢迎页/完成页左侧放品牌侧边图（深色 + Trim logo + slogan）；② 内部页顶部放品牌横幅（深色 + Trim 字样）；③ 主按钮用 accent 色 #8B8EE0；④ 界面文字全中文；⑤ 不改变安装逻辑、不影响 electron-updater 差量更新、不新增 npm 依赖。

ℹ️
关键约束：electron-builder 的 NSIS 目标使用 MUI2（Modern UI 2），图片素材必须是 BMP 格式（electron-builder 内部会自动转换，但直接给 BMP 最稳妥）。侧边图标准尺寸 164×314，顶部横幅标准尺寸 150×57。

三种方案对比

从「极简」到「完全定制」，三种路线各有取舍。

方案做法优点缺点参考应用
A · oneClick 一键安装 oneClick:true，只有一个小进度窗口（约 400×180），无向导页 极简、现代感最强、用户体验最流畅 失去自定义安装目录、快捷方式选择、perMachine 选择 VS Code、Discord、Figma
B · 向导式 + 品牌视觉 ⭐推荐 保留 oneClick:false 向导，加 installerSidebar / installerHeader / language，可选自定义 .nsh 改配色 保留全部功能控制 + 品牌视觉提升明显 + 成本低（2 张图 + 配置） 主区仍是浅色（MUI2 限制），深色全覆盖需 .nsh Slack、Obsidian、Typora
C · 深度自定义 MUI 写完整自定义 .nsi/.nsh 脚本，用 MUI_UI 自定义界面资源、改所有颜色/字体/按钮 完全定制，可做深色全覆盖 开发成本高、NSIS 脚本调试麻烦、electron-builder 升级可能不兼容 部分商业软件
⚠️
为什么不选 A（oneClick）：Trim 的 perMachine:false + asInvoker 免 UAC 设计依赖用户确认安装到 %LOCALAPPDATA%\Programs；且用户可能需要改安装目录、选择是否创建桌面快捷方式。oneClick 会把这些全部跳过，与现有设计冲突。方案 B 在保留向导的同时提升视觉，是性价比最高的路线。

推荐方案配置

修改 package.json 的 build.nsis 段，新增 5 个字段。图片素材放 build/ 目录（buildResources 默认路径）。

json · package.json → build.nsis（替换现有 nsis 段）
"nsis": {
  "oneClick": false,
  "perMachine": false,
  "allowElevation": true,
  "allowToChangeInstallationDirectory": true,
  "createDesktopShortcut": true,
  "createStartMenuShortcut": true,
  "shortcutName": "Trim",
  "differentialPackage": true,
  "deleteAppDataOnUninstall": true,
  "artifactName": "${productName}-Setup-${version}.${ext}",

  // ===== 新增：品牌视觉 =====
  "installerSidebar": "build/installerSidebar.bmp",
  "uninstallerSidebar": "build/uninstallerSidebar.bmp",
  "installerHeader": "build/installerHeader.bmp",
  "installerIcon": "src/assets/ico/Trim.ico",
  "uninstallerIcon": "src/assets/ico/Trim.ico",
  "language": "2052"
}

installerSidebar

欢迎页 + 完成页左侧品牌图，164×314 BMP。深色背景 + Trim logo + slogan + 版本号。

installerHeader

内部页（许可/目录/进度）顶部横幅，150×57 BMP。深色渐变 + Trim 字样。

language: "2052"

NSIS 语言代码 2052 = 简体中文。界面所有按钮/标题/提示全中文，不再是英文 MUI 默认。

品牌图片素材

下方 canvas 实时渲染品牌图，点击「下载 BMP」即可获取可直接放入 build/ 目录的素材。配色对齐 Trim 品牌色。

installerSidebar.bmp 164 × 314

欢迎页/完成页左侧品牌图。深色渐变背景，左侧 accent 竖条，Trim logo + slogan + 版本号。

installerHeader.bmp 150 × 57

内部页顶部横幅。深色渐变背景，左侧 Trim 字样，右侧 accent 细竖线，底部细线。

💡
uninstallerSidebar.bmp：可直接复制 installerSidebar.bmp 重命名为 uninstallerSidebar.bmp（卸载页侧边图与安装页一致即可）。如需区分，可在 slogan 处改为"卸载 Trim"。下载上方侧边图后手动重命名即可。

进阶：自定义 MUI 配色（可选）

如果希望主按钮和界面文字色更彻底地对齐品牌色，可以通过 electron-builder 的 nsis.include 注入自定义 .nsh 脚本。以下为可选增强，不加也能达到上方设计稿效果。

nsh · build/trim-mui.nsh（新建文件）
; Trim 品牌色 MUI 定制
; 通过 electron-builder nsis.include 注入，在 MUI2 初始化前生效

; 主按钮背景色（accent 深 #8B8EE0）
!define MUI_INSTALLBUTTONCOLOR "0x00E08B8B"

; 向导页标题文字色（品牌前景 #171832，BGR 倒序）
!define MUI_INSTALLWELCOME_TITLECOLOR "0x00321817"

; 欢迎页副标题色
!define MUI_INSTALLWELCOME_SUBTITLECOLOR "0x00555555"

; 完成页标题色
!define MUI_FINISHPAGE_TITLECOLOR "0x00321817"

; 进度条颜色（accent）
!define MUI_INSTFILESPAGE_PROGRESSBAR_COLOR "0x00E08B8B"
json · package.json → build.nsis 追加一行
"include": "build/trim-mui.nsh"
⚠️
NSIS 颜色是 BGR 倒序：HTML 的 #RRGGBB 在 NSIS 里要写成 0x00BBGGRR（例如 #8B8EE0 → 0x00E08B8B）。.nsh 脚本调试成本较高，建议先不加 include，只用图片素材 + language 即可达到设计稿 90% 的效果；确认需要更深度定制时再加。

实施步骤与验收

从零到构建出美化后的安装包，共 6 步。

1

创建 build 目录并放入图片素材

在项目根目录新建 build/ 文件夹（electron-builder 默认 buildResources 路径）。从本页「品牌图片素材」节下载 installerSidebar.bmp 和 installerHeader.bmp 放入；复制 installerSidebar.bmp 重命名为 uninstallerSidebar.bmp。

2

修改 package.json 的 nsis 配置

按本页第 3 节的配置替换 build.nsis 段，新增 installerSidebar / uninstallerSidebar / installerHeader / installerIcon / uninstallerIcon / language 六个字段。可选：第 6 节的 include + trim-mui.nsh。

3

构建安装包

运行 npm run build:setup，electron-builder 会自动读取 build/ 目录的图片素材并嵌入 NSIS 安装包。构建产物在 Trim goujian/build-release/Trim-Setup-x.y.z.exe。

4

真机安装验收

双击运行 Trim-Setup-x.y.z.exe，逐项检查：① 欢迎页左侧品牌图是否正常显示（非纯白）；② 内部页顶部横幅是否深色品牌色（非默认蓝色）；③ 所有界面文字是否全中文；④ 主按钮是否 accent 色；⑤ 完成页品牌图正常；⑥ 卸载程序侧边图正常。

5

验证自动更新不受影响

美化只改了 nsis 视觉字段，differentialPackage:true 不变，.blockmap 和 latest.yml 正常生成。构建后确认产物目录同时存在 Setup.exe + .exe.blockmap + latest.yml 三件套。

6

提交与发布

验收通过后提交 package.json + build/ 目录（3 张 bmp）。发版时按第十一部分的 GitHub Releases SOP 上传三件套。注意：图片素材变更不影响版本号，但建议随下一个版本一起发布。
