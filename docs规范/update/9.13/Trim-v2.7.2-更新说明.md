# Trim v2.7.2 更新说明（2026-09-13）

> 用户反馈驱动：右上角原生窗口按钮在启动页期间不再有独立色块，彻底融入画面（参考 Mineradio 效果）。

---

## 一、右上角按钮「透明覆盖层」（本版唯一改动）

- **v2.7.1 的做法与局限**：启动页期间把覆盖层染成渐变顶色 `#efedfb`——但启动页背景是动态 WebGL 画面，固定色块与动态画面之间仍有细微接缝。
- **v2.7.2 的做法**：`TITLEBAR_OVERLAY.color = 'rgba(0, 0, 0, 0)'`——**覆盖层完全透明**，min/max/close 按钮直接浮在网页内容上：
  - 启动页期间：按钮浮在 WebGL 流线画面上（与 Mineradio 同款效果）；
  - 常规态：按钮浮在 DOM 标题栏底色上，视觉与之前完全一致；
  - 最大化/材质切换：跟随底层 DOM，任何场景无色块接缝，也不再需要任何动态换色逻辑。
- **前提**：透明色下「按钮悬停高亮渲染错误」的 Electron bug 已在 37/38/39 分支修复（electron#48193，本应用 Electron 44.1.1），可安全使用。
- **清理**：v2.7.1 的 `splash:overlay` 染色通道（main.js handler + preload `setSplashOverlay` + splash.js 调用）已全部删除——透明是正解，染色方案无存在必要。
