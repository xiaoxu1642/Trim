# Trim 使用说明

> 由小旭个人开发制作，仅供个人测试交流使用。Windows 11 清理与优化工具，Fluent Design 原生风格。
> 版本 **2.0** · 适用 Windows 11 22H2 及以上（已在 27H2 Build 29648 验证）· 需要 PowerShell 7

---

## 零、v2.0 更新摘要

本版聚焦「信息架构 + 视觉可读性 + 动效规范」三件事，功能模块本身未增删。

**信息架构（侧边栏）**

- 导航重组为四个分组：**清理**（系统概览 / 磁盘清理 / 内存清理 / 系统维护）→ **优化**（电脑优化中心 / 启动项管理 / 右键管理）→ **工具**（磁盘测速 / 网络测速 / 实时网速 / 快捷指令）→ **记录**（日志），底部固定 **设置 + 主题切换**。
- 「优化」分组整体上移，紧贴「系统维护」下方，不再与清理组之间留出空档。
- 父级条目（电脑优化中心、右键管理）的分类子菜单默认折叠，展开时按内容实际高度撑开（上限 600px），**不再自动延展到窗口底部**；「日志」随之被自然下推，最多抵达「设置」上方。

**视觉与可读性**

- 深色主题重新标定表面色阶（carbon ladder）：侧边栏选中态、卡片描边回归原底色，去除了高对比黑块与突兀绿块。
- 浅色主题下面板文字、导航项、副标题全部改为高对比色，标题 `#1c1e24`、正文 `#4b505b`，满足 WCAG 对比要求。
- 首页「系统健康度」卡片精简为**仅显示状态**（如「状态良好」），移除环形进度与附加指标；概览页四个圆角容器默认尺寸收紧（内边距 14px、最小高 86px）。
- 所有图标资源统一取自仓库 `src/assets/ico/` 目录（已随 `src/**/*` 打进主程序内部，删除外部 `ico/` 目录不影响运行）：`Trim.ico` 同时用于 Electron 主/子窗口图标、任务栏与安装包图标、Tauri 安装器 `src-tauri/icons/icon.ico` 及 `build/icon.ico`（三处逐字节一致）。

**动效规范（Motion.Lab）**

- 全应用按钮统一改为**点击波纹（ripple-click）**：480ms 扩散淡出，节点绝对定位脱离文档流，**不再改变按钮尺寸**。此前导致按钮点击后整组错乱的果冻动效（jello）已彻底移除。
- 新增**鼠标拖尾**动效，仅在应用窗口范围内生效（`position: fixed` 覆盖视口，图层不拦截任何指针事件），可在 **设置 → 外观 → 鼠标拖尾** 开关，状态存于 `localStorage`。
- 系统「减弱动效」偏好（`prefers-reduced-motion`）下，波纹与拖尾完全不创建 DOM 节点，兼顾无障碍与性能。

**交互细节**

- 「磁盘清理」页各分类分组**默认折叠**，需要时逐项展开，首屏更紧凑。
- 窗口材质（Mica / Acrylic / 薄亚克力）与皮肤（经典 / 液态玻璃）选项链路复核修复：设置项经 `appearance:set-material` IPC 调用 `setBackgroundMaterial`，同时写入 `body[data-material]` 驱动 CSS 分层，失败自动回滚并提示。

**发布形态与目录**

- 源码仓库：`C:\kaifa\TuneForge`（仅源码，不含构建器与产物）。
- 构建区：`C:\kaifa\TuneForge goujian\`，包含 `trim-installer\`（Tauri 安装器工程）、`build-release\`（electron-builder 输出）与两份成品。
- **Electron 便携版**：`Trim-Portable-2.0.0.exe`（单文件，免安装）。
- **Tauri 单文件安装器**：`Trim-Setup-2.0.0.exe`，由 `trim-installer` 工程 `tauri build --no-bundle` 产出独立 EXE。
- 构建顺序（安装器在编译期嵌入程序包，顺序不可颠倒）：
  1. `npm run build:portable` 生成 `build-release\win-unpacked\`；

| 页面 | 说明 |
| --- | --- |

## 二、操作流程

### 1. 磁盘清理

1. 进入「磁盘清理」页面，点击 **扫描**，等待扫描完成；
2. Windows 系统分类采用二级目录（过时文件 / 系统相关 / 缓存文件 / 应用程序 / 临时文件），可展开后单独勾选；
3. 勾选要清理的项目，点击 **清理** 执行；
4. 风险等级说明：低风险可直接清理；**高风险项（共 4 项）必须勾选「强制删除」才会执行**，请逐项核对。

覆盖内容：Windows 系统缓存与临时文件、显卡缓存（NVIDIA / AMD / Intel）、浏览器缓存（Chrome / Edge）、应用缓存（Steam、网易云音乐、微信、QQ、抖音）、QQ 与微信文件目录清理。

**图片预览**：文件目录清理条目右侧的 **预览 (N)** 按钮会打开**独立「图片预览」窗口**（不再占用主窗口）：支持左右方向键切换、缩放（−/+）、1:1 还原、旋转，窗口内可直接 **删除** 当前图片——删除后主窗口的文件列表与容量统计会**实时同步**。

### 2. 内存清理

1. 顶部 4 张卡片（与系统概览同款 2x2 布局，最大化时一行）实时展示：物理内存使用率（带进度条）、可用内存、页面文件使用、系统缓存；
2. **内存清理区域**共 6 项，分门别类勾选后点击 **开始清理**（或对单项点「清理该项」）：
   - 工作集、低优先级备用列表、合并物理内存页（默认勾选，安全）
   - **修改列表、备用列表（全部）为高风险**，执行前会弹红色二次确认，可能导致系统短暂卡顿；
   - **顽固软件专杀**（默认不勾选）：一次性结束 MuMu 模拟器 / 网易 UU 远程 / 抖音 / 剪映 / WPS 金山办公 / 微软电脑管家 的后台常驻与守护进程（含其前台进程，请先保存工作），执行结果右上角 Toast 并回传日志；
   - **点击区域条目**可弹窗查看该区域的详细简介（本地 + 联网 AI）；
3. **应用进程管理**：主页面「运行中的进程」为**一行式入口卡片**——左侧为标题与图标、中间为内容回显区（默认显示「尚未管理进程 · 点击『去管理』打开管理窗口」，或当前进程总数摘要）、右侧为 **去管理** 按钮，卡片下方有操作入口提示文字：
   - 点击 **去管理** 打开独立「应用进程管理」窗口，可与主窗口并排操作；
   - 同路径的进程自动合并为一条（参照任务管理器进程树）；**打开时默认折叠**，主进程名前有**展开箭头**，点击分组行可展开各子进程单独结束、再次点击收起，箭头随状态旋转 90°；
   - 各应用图标**懒加载自其可执行文件路径**，提取失败时自动回退显示随包内置兜底图标（`Trim.ico`）；
   - 支持按名称或 PID 搜索、手动刷新，结束进程前有二次确认；
   - **结果实时回显**：窗口内结束进程后，最新进程统计会即时回显到主页面卡片的中间内容区（如「当前共 N 个运行中的进程」）；
4. 清理完成后显示释放的内存量，并自动刷新内存信息。

> 说明：内存清理调用 Windows Native API（`NtSetSystemInformation`，参考 Mem Reduct），**需要管理员权限**；无管理员权限时清理会失败并提示提权。释放量取决于当前系统状态，通常为已用内存的 10%–50%。

### 3. 电脑优化中心

1. 进入「优化电脑」页面，各优化项按 17 个分组展示为卡片；
2. 点击卡片查看详情，含执行步骤、风险等级、优缺点分析；
3. 点击 **立即执行** 前，应用会自动检查系统还原点：
   - 未创建还原点 → 弹出警示窗口，建议先创建；
   - 5 天内已创建 → 右上角轻量提醒；
4. 支持**勾选部分卡片**后点 **执行所选优化**，或点 **全选执行** 一次执行当前页全部项目；
5. **高危安全操作**（禁用 UAC、关闭 Defender、禁用 70+ 服务、BCD 超优化等）执行前会弹**红色警示二次确认**；
6. **任务调度-顽固软件策略专杀**（无还原）：一次性将 MuMu 模拟器 / 网易 UU 远程 / 微软电脑管家 等后台常驻服务的启动类型改为「手动」并立即停止，同时停止 WPS 云文档服务、删除 WPS 更新计划任务并关闭其自动升级，从源头杜绝顽固软件后台自启与残留保活；
7. 执行过程中有实时进度条，完成后 Toast 提示。

> **重要提醒**：108 个优化项中 14 项为高风险，其中 **13 项执行后无法一键还原**（仅「MMCSS 系统增强」提供还原步骤）。「顽固软件策略专杀」为一次性策略，不提供自动还原。涉及服务、驱动、注册表与启动参数的改动，请务必**先创建系统还原点**再执行。

### 4. 系统还原点管理

在「电脑优化中心」页面右上角点击 **系统还原点** 打开弹窗，可查看各磁盘的保护状态、还原点数量与最近还原点；点击 **创建还原点** 为所有已启用保护的磁盘创建还原点。优化导致异常时可在系统设置中执行系统还原回退。

### 5. 启动项管理

1. 进入「启动项管理」页面自动扫描（注册表 Run/RunOnce、启动文件夹、登录与开机计划任务）；
2. 勾选后可执行 **启用 / 禁用**（可逆）或 **删除**（先备份，不可逆）；
3. 可 **打开所在位置** 查看文件，或手动 **添加** 启动项（同名会提示冲突，不会静默覆盖）；
4. **点击启动项条目**（非按钮区域）即可弹窗查看详细简介（本地 + 联网 AI）。

### 6. 右键管理

1. 进入「右键管理」页面，按 13 类自动扫描：文件、EXE文件、LNK文件、目录、文件夹、驱动器、回收站、目录背景、桌面背景、此电脑、库、发送到、UWP应用；
2. 交互方式：**勾选 = 启用，取消勾选 = 禁用**（可随时改回）；
3. 行内 **备份并删除** 为不可逆操作，删除前会自动备份注册表项与「发送到」文件；
4. 左侧另有聚合视图（全部 / 磁盘分区 / 新建菜单 / 打开方式 等），便于按场景筛选；
5. 点击条目可查看详情，并可调用联网 AI 查看简介。

### 7. 磁盘测速

设置测试路径（默认自动检测当前用户的「下载」目录）、块大小、队列深度与线程数后点击开始。测试会在目标目录创建临时文件，完成后自动删除。支持保存历史记录并对比。

### 8. 网络测速

点击开始后，在测速页面选择 **SpeedTest.cn** 或 **中国科大** 节点测试真实带宽。本模块需要联网，测速数据由对应站点提供。

### 9. 实时网速

进入页面即开始采集，显示上下行速率曲线与丢包率，可暂停、切换网卡；离开页面自动停止采集。

**记录数据**：点击右上角 **记录数据** 开始采集，再次点击 **停止记录** 自动生成报告（持续时间、最高/最低/平均下载上传速率、每秒网速折线图），保存到缓存目录 `%APPDATA%\Trim\cache\realtime-reports\`；点击 **查看报告** 可回看历史记录、删除单条或清空全部。报告保留 **7 天自动清理**；点「清空图表」会同时放弃进行中的记录。

### 10. 设置

- **功能入口**：三张入口卡片（安装路径绑定 / 大模型管理 / 字体选择）**固定一行排列，随窗口宽度自适应均分**，点击各自按钮打开统一样式的弹窗或独立窗口；
- **安装路径绑定**：自动扫描并绑定各软件安装路径与文件目录，点击「去设置」在弹窗中分门别类管理（安装路径 / 文件目录 / 缓存目录，带软件真实图标）；
- **大模型管理**：点击「去管理」打开**独立「大模型管理」窗口**（可拖动、缩放、与主窗口并排显示），按分组配置四个模型项的启用状态、接口地址、密钥与模型名，点击分组标题可展开/折叠，配置完成点 **完成** 关闭；
- **字体选择**：点击「去选择」打开字体弹窗，调整整个应用界面的显示字体：
  - **内置 MiSans 可变字体**（字重 100–1000 无级调节），也支持选择系统字体或导入一款自定义字体（.ttf / .otf / .woff / .woff2）；
  - **字重滑块**（100–1000，显示粗细百分比）与 **字号滑块**（12–24px，全局生效）；
  - 拖动滑块与切换字体时，效果**仅实时预览于弹窗内的「字体预览」区**，不影响界面其他部分；点击右下角 **应用** 后才应用到整体界面并保存配置，弹窗保持打开；
  - 「恢复默认」回退为 MiSans · 400 字重 · 16px（同样需点「应用」生效）；配置保存在 `%APPDATA%\Trim\settings.json`；
- **系统信息**：应用版本、Electron、操作系统等运行环境信息；
- **清理选项 / 显示**：清理行为开关与深浅色主题切换；
- **关于与说明**：点击「查看说明」弹出本文档。

> 全应用弹窗分两类：**轻量确认/表单类弹窗**（路径绑定 / 字体 / 模型选择 / AI 简介 / 各类确认框）共用同一套三段式弹窗骨架与样式，打开/关闭均经统一 IPC 通道记录到操作日志；**独立窗口类**（应用进程管理 / 大模型管理 / 图片预览）为独立 BrowserWindow，可与主窗口并排显示、独立缩放，打开与关闭同样记录到操作日志。

### 窗口尺寸

主窗口默认并最小为 **1294×870（客户区渲染，`devicePixelRatio = 1`）**，可自由拉伸放大或最大化，**不允许缩小**到该尺寸以下。

### 独立窗口显示（无黑闪）

「应用进程管理 / 大模型管理 / 图片预览」三个独立 BrowserWindow 均采用 `show: false` + `ready-to-show` 页面首帧渲染完成后才显示，从根源消除打开瞬间的背景色空帧黑闪（图片预览窗的黑色背景在首帧前不再单独闪现）。

## 三、联网 AI 简介怎么用

启动项管理、右键管理、内存清理（区域点击弹窗内）提供「简介」能力，采用**本地简介 + 联网 AI 简介**两层设计（电脑优化中心详情弹窗已移除简介区块，避免与绿红优缺点对比重复）：

- **本地简介**：随程序内置，打开详情立刻显示，**不联网、不上传任何信息**；
- **联网 AI 简介**：只有当你再点击一次 **获取 AI 简介** 时才会发起请求，且只上传「项目名称 + 厂商/分组」，不包含任何注册表路径、文件路径或账号信息；
- 各模块的 AI 简介**互不联动**：各自选择模型、各自缓存（7 天有效），改一处不会影响另外一处；
- 若所选模型尚未启用，点击「获取AI简介」会**直接打开「大模型管理」独立窗口**引导你启用，简介面板不再显示模型名称与验证状态。

### 配置模型

在 **设置 → 大模型管理 → 去管理** 中配置，共四个模型项：

| 模型项 | 说明 |
| --- | --- |
| 百度千帆 | 千帆 web_summary 接口，模型名从 thinking / auto_thinking / non_thinking 中选择 |
