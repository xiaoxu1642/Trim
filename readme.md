# Trim 使用说明

> Trim 是一款 Windows 11 清理与优化小工具，中文界面，原生 Fluent Design 风格。
> 由小旭个人开发，仅供个人测试交流使用，使用风险请自行承担。
> 版本 **2.6**，适用 Windows 11 22H2 及以上，电脑上需要装有 **PowerShell 7**；内存清理功能需要**以管理员身份运行**。

---

## 一、功能一览

左侧导航共 12 个页面。系统体检页点内存、磁盘小图标可以直接跳到对应清理页。

| 页面 | 能做什么 |
| --- | --- |
| 系统体检 | 只读体检结论（正常/注意/异常 + 证据等级），CPU、内存、磁盘占用实时监控，本机硬件信息 |
| 磁盘清理 | 5 大类共 68 个清理项，扫描后显示风险等级和可释放空间，按需勾选清理 |
| 内存清理 | 查看内存占用，按 6 个区域勾选释放内存；从这里进入「应用进程管理」独立窗口 |
| 电脑优化中心 | 16 个分组共 125 个优化项，可单项执行，也可勾选一批一起执行 |
| 启动项管理 | 扫描注册表、启动文件夹和计划任务里的开机自启项，可启用、禁用、删除、手动添加 |
| 右键管理 | 按 13 个类别扫描右键菜单，勾选即启用、取消即禁用，删除前自动备份 |
| 磁盘测速 | 测顺序读写、4K 随机读写、IOPS 和延迟，参数可调 |
| 网络测速 | 通过 SpeedTest.cn 或中国科大节点测真实带宽 |
| 实时网速 | 常驻显示网卡上下行速度和丢包率，可录制并生成折线图报告 |
| 系统还原点 | 从优化中心右上角打开，查看保护状态、创建还原点 |
| 操作日志 | 查看和导出全部操作记录 |
| 设置 | 安装路径绑定、大模型管理、字体选择、主题与外观、动效、系统信息、关于 |

## 二、磁盘清理

**操作步骤：**

1. 进入页面后点 **扫描大小**，等待扫描完成；大小显示为 **—** 的条目表示当前权限无法统计（系统目录需管理员权限、注册表项本身没有字节概念），不代表里面没有可清理内容，也不等于 0 字节；
2. Windows 系统类是二级目录（过时文件 / 系统相关 / 缓存文件 / 应用程序 / 临时文件），展开后可单独勾选；
3. 勾好要清理的项目，点 **开始清理**。工具栏有三个可选项：
   - **强制删除**：遇到被占用的文件不再重试，尽量清干净；
   - **自动重建目录**（默认开启）：清理后把空目录建回来，避免依赖这些目录的软件报错；
   - **删除进回收站**：文件先进回收站，能还原；注册表项和 DISM 清理没有回收站概念，仍会直接执行；
4. 每个条目行尾的 **明细** 按钮可以先看看会删哪些文件（只读预览，最多列 600 条，可复制完整清单）；清理后如果有文件被占用没删掉，会提示「N 项仍有残留」，关掉相关软件或重启后再试即可；**释放空间按删除前后的实际差值统计**，只删掉一部分的条目不会按账面大小冒领，会计入「清理失败」提示并在应用日志里标为部分成功；
5. **风险等级**：低风险项放心清；高风险项共 2 个——**Windows Installer 补丁缓存**和 **DISM 组件清理**，必须勾上「强制删除」才会执行，下手前请逐项确认。

**覆盖范围：** Windows 缓存和临时文件、显卡缓存（NVIDIA / AMD / Intel）、浏览器缓存（Chrome / Edge / Firefox / QQ浏览器，自动覆盖全部用户 Profile）、常用软件缓存（Steam、Epic、Office、VS Code、JetBrains、npm/pip/NuGet、网易云音乐、微信、QQ、抖音）、注册表隐私痕迹（最近文档、运行记录、名称缓存），以及 QQ、微信接收文件目录。

**规则库（清理清单）更新：**

- 点工具栏 **更新规则库** 即可在线检查更新，程序会自动依次尝试多个下载源；下载内容会做完整性校验，损坏或被篡改的更新包会被直接拒绝，更新后立即生效，无需重启软件；
- 没装的软件对应条目扫描时会自动隐藏（比如没装 Firefox 就不显示它）；
- 如果某条目要求先关闭相关程序（如 Chrome、资源管理器），扫描结果的路径列会出现琥珀色「需关闭: xxx」标签；**执行时程序还开着的话，整条自动跳过并写明原因**，不会清一半留一半；
- 想加自己的清理规则：把同结构的 JSON 文件放进 `%APPDATA%\Trim\cleanup\custom\`，同名条目覆盖内置规则，新条目自动追加；
- 默认下载源取不到时（例如私有仓库返回 404），可在 `%APPDATA%\Trim\cleanup\update-source.json` 里配置自己的下载地址和请求头；程序位于 git 仓库内时也会尝试直接用本机 git 拉取。

**图片预览：** 文件目录类条目右侧的 **预览 (N)** 按钮会打开独立的图片预览窗口，支持左右方向键切换、缩放（−/+）、1:1 还原、旋转，窗口内可以直接删除当前图片，删掉后主窗口的文件列表和容量统计会实时同步。

## 三、内存清理与应用进程管理

**内存清理：**

1. 顶部 4 张卡片实时显示物理内存使用率（带进度条）、可用内存、页面文件占用和系统缓存；
2. 清理区域共 6 项，勾选后点 **开始清理**，也可以对单项点「清理该项」：
   - 工作集、低优先级备用列表、合并物理内存页：默认勾选，安全；
   - **修改列表、备用列表（全部）属于高风险**，执行前会弹红色二次确认，执行时系统可能短暂卡顿一下；
   - **顽固软件专杀**（默认不勾）：一次性结束 MuMu 模拟器、网易 UU 远程、抖音、剪映、WPS、微软电脑管家的后台常驻和守护进程（包括前台窗口，请先保存手头工作），结果以右上角提示和日志形式反馈；
   - 点区域条目可看详细简介（本地简介 + 可选的联网 AI 简介）；
3. 清理完成后会显示释放了多少内存，并自动刷新数据。

> 原理与权限：内存清理调用 Windows 系统接口（和 Mem Reduct 同款原理），**必须管理员权限**，没有权限会提示提权。释放多少取决于当前系统状态，一般是已用内存的 10%–50%。

**应用进程管理：**

内存清理页的「运行中的进程」是一张一行式入口卡片，点右侧 **去管理** 打开独立窗口，可与主窗口并排操作：

- 同一路径的进程自动合并成一组（类似任务管理器的进程树），默认折叠，点行展开/收起，可对单个子进程单独结束；
- 应用图标直接从可执行文件提取，提取失败时显示内置兜底图标；
- 支持按名称或 PID 搜索、手动刷新，结束进程前二次确认；
- 在子窗口结束进程后，最新统计会实时回传到主页面卡片上。

## 四、电脑优化中心与系统还原点

1. 进入「优化电脑」页，125 个优化项按 16 个分组显示成卡片；
2. 点卡片可看详情：执行步骤、风险等级、**预期效果**（明显/一般/微小/未验证的经验分级，非本机实测）、优缺点；
3. 点 **立即执行** 前会自动检查还原点：从没建过会弹窗建议先建，5 天内建过只轻量提醒；
4. 可勾选多张卡片后点 **执行所选优化**，或点 **全选执行** 跑当前页全部项目；
5. **高危操作**（禁用 UAC、关闭 Defender、批量禁用 70 多个服务、BCD 超优化等）执行前会弹红色警示二次确认；
6. 「任务调度 - 顽固软件策略专杀」（无还原）：把 MuMu 模拟器、网易 UU 远程、微软电脑管家等后台常驻服务改为手动并立即停止，同时停掉 WPS 云文档服务、删除 WPS 更新计划任务并关闭自动升级；
7. 执行时有实时进度条，完成后弹提示；**执行成功后程序会立即回读注册表核对**，读回值与预期不符（例如被组策略或安全软件改回）会明确提示「已执行但读回校验不符」，不会静默假成功；
8. **已应用清单（v2.6 新增）**：每次执行前都会把「改了什么」记入本机状态文件（含 BCD、服务等注册表备份覆盖不到的步骤）；启动时自动核对，发现「执行中断、被系统回写导致状态不明」的项，优化中心顶部会出现提示条，可**一键还原**；
9. 优化项日后从目录退役时，启动会**自动按执行前记录的原值还原**历史改动并清理备份，不产生孤儿记录。

> **重要**：125 项里有 15 项高风险，其中 **11 项执行后无自动还原**（其余 4 项支持一键还原）。凡是动服务、驱动、注册表、启动参数的，务必**先建系统还原点**。

**系统还原点：** 在优化中心右上角点 **系统还原点** 打开弹窗，能看到各磁盘的保护状态、还原点数量和最近一次还原点时间；点 **创建还原点** 会为所有已开启保护的磁盘建还原点。优化后万一异常，去系统设置里还原即可。

## 五、启动项管理

1. 进页面自动扫描（注册表 Run/RunOnce、启动文件夹、登录与开机计划任务）；
2. 勾选项后可 **启用/禁用**（随时可逆）或 **删除**（删除前自动备份，不可逆）；
3. 可 **打开所在位置** 找到源文件，也可手动 **添加** 启动项，重名会提示冲突，不会静默覆盖；
4. 点条目（非按钮区域）可看详细简介，支持联网 AI 简介。

## 六、右键管理

1. 进页面按 13 类自动扫描：文件、EXE、LNK、目录、文件夹、驱动器、回收站、目录背景、桌面背景、此电脑、库、发送到、UWP 应用；
2. **勾选 = 启用，取消勾选 = 禁用**，随时可以改回来；
3. 行内 **备份并删除** 是不可逆操作，删除前会自动备份注册表项和「发送到」文件；
4. 左侧有聚合视图（全部 / 磁盘分区 / 新建菜单 / 打开方式 等），方便按场景找；
5. 点条目看详情，也可调用联网 AI 简介。

## 七、磁盘测速 / 网络测速 / 实时网速

- **磁盘测速**：设置好测试路径（默认自动选当前用户的「下载」目录）、块大小、队列深度和线程数后开始；测试会在目标目录建临时文件，结束自动删除，可保存历史记录做对比。
- **网络测速**：点开始后选 **SpeedTest.cn** 或 **中国科大** 节点，需要联网，数据由对应站点提供。
- **实时网速**：进页面开始采集，显示上下行曲线和丢包率，可暂停、切换网卡，离开页面自动停。点右上角 **记录数据** 开始录制，再点 **停止记录** 自动生成带每秒折线的报告，存在 `%APPDATA%\Trim\cache\realtime-reports\`，报告保留 **7 天自动清理**。

## 八、设置页说明

**三张功能入口卡片（固定一行）：**

- **安装路径绑定**：自动扫描并绑定各软件的安装路径和文件目录，弹窗内按「安装路径 / 文件目录 / 缓存目录」分类管理，带软件真实图标；
- **大模型管理**：打开独立窗口配置，详见下一节；
- **字体选择**：内置 MiSans 可变字体（字重 100–1000 无级可调），也支持系统字体和导入自定义字体；字重、字号先在弹窗里预览，点 **应用** 全局生效，配置存在 `%APPDATA%\Trim\settings.json`。

**显示与外观：**

- **外观固定浅色**：应用固定为浅色模式，不随系统主题变动；「预设主题选择」切换内置渐变墙纸（无 / 极光 Aurora / 落日 Sunset / 石墨 Graphite）；「主题颜色选择」自定义界面强调色；
- **窗口材质**：Mica / Mica Alt / 亚克力 / 细亚克力四种 Windows 原生材质，右上角总开关一关就是普通不透明界面（会记住你的选择，再开恢复）；主窗口和三个子窗口同步生效；
- **背景图片**：可导入图片作为主界面背景，**雾化度** 控制图片和界面融合的朦胧感，**背景模糊度** 是 0–100% 无级滑块，控制面板的液态玻璃磨砂强度（0% 为经典不透明面板，100% 为完整磨砂；旧版皮肤偏好自动迁移）；支持多图管理和一键打开存放目录；
- **动效设置**：鼠标拖尾开关（只对当前窗口生效）+ 动效选择（完整 / 标准 / 磨砂 / 关闭四档液态玻璃强度）。

**其他：**

- **系统信息**：应用版本、数据目录形态（标准安装/便携模式）、Electron、操作系统等运行环境信息，默认折叠；
- **更新镜像**（v2.6 新增）：默认「自动」——优先 GitHub 直连，失败自动回退镜像线路；也可固定走某条线路。下载内容一律经更新清单哈希强校验，镜像只是传输通道；
- **便携模式**（v2.6 新增）：在程序 exe 同目录新建空文件 `Trim.portable`，下次启动后所有数据（配置/日志/备份/缓存）改存程序目录的 `data` 子文件夹，不再写入 `%APPDATA%\Trim`；删除标记文件即恢复标准模式；
- **关于与说明**：点「查看说明」弹出本文件。

> 小知识：主窗口默认并最小为 **1294×870**，可以拉大、最大化，但不能再缩小；应用进程管理、大模型管理、图片预览是三个独立窗口，可以和主窗口并排使用，打开时不会闪黑屏。

## 九、联网 AI 简介怎么用

启动项、右键管理、内存清理的详情里提供「简介」，分两层：

- **本地简介**：内置在程序里，打开就有，**不联网、不上传任何信息**；
- **联网 AI 简介**：只有你主动点 **获取 AI 简介** 才会请求网络，且只上传「项目名称 + 厂商/分组」，不含注册表路径、文件路径或账号信息；
- 各模块的 AI 简介各自独立：分别选模型、分别缓存（7 天有效）；
- 所选模型没启用时，点「获取 AI 简介」会直接打开大模型管理窗口引导启用。

**配置模型：** 在 **设置 → 大模型管理 → 去管理** 里配置，共四项：百度千帆、知乎直答、秘塔 AI、自定义模型（兼容 OpenAI chat/completions 协议）。**所有内置模型默认关闭、密钥留空**；填入密钥点保存后会自动发一条测试消息，校验通过才启用，密钥只保存在本机 `%APPDATA%\Trim\settings.json`，不会上传。

## 十、安全须知

1. 清理、右键菜单修改、启动项删除，建议保持二次确认开启；
2. **执行高风险优化项前一定先建系统还原点**——15 项高风险里 11 项无自动还原；
3. 删除类操作（右键项、启动项、文件清理）执行前会自动备份，但备份代替不了还原点，动系统级设置前还是建议先建还原点；
4. 磁盘清理的两个高风险项（Windows Installer 补丁缓存、DISM 组件清理）会影响系统更新的卸载能力，理解后再勾「强制删除」；
5. 只有网络测速和联网 AI 简介会访问外网，其余功能全部在本机完成；
6. 本工具仅供个人测试交流，使用风险自负。

## 十一、不做的事（已知无效或有代价的常见「优化」）

Trim 的原则：**说不清收益的改动，宁可不做**。以下常见「优化技巧」经实测或公开机制分析后，Trim 刻意不提供或已收敛为只读提示——列出来说明原因，帮你省下试错的功夫：

- **清空整个待机列表「释放内存」**：待机列表本来就计入可用内存，强行清空丢掉的是热缓存（公开实测中曾出现清掉近 19 GB 系统缓存只换来几百 MB「可用内存」的情况）。Trim 的内存清理只提供工作集、低优先级备用列表等收益明确的区域；
- **MMCSS 多媒体调度游戏提优先级**：实测无可测收益，相关注册表调校已不提供；
- **禁用全屏优化（FSO）/ 关 MPO**：会连带丢失 Auto HDR 与可变刷新率，或让画面全部改走合成影响录制捕获，代价大于收益；
- **计时器合并、动态时钟等 BCD「玄学参数」**：机制上影响的是省电而非性能，感知不到收益；Trim 保留的 BCD 项已收敛到时钟同步类；
- **高频率自动「内存整理」**：反复清空工作集只会把数据换回页面文件再读回来，徒增磁盘 IO；
- **禁用系统服务「越全越好」**：盲目禁用会破坏更新、同步、打印等基础能力；Trim 的批量禁用清单里，商店与同步相关服务保持系统默认不再修改；
- **MSI 中断模式 / 中断亲和性调优**：无法可靠验证设备是否支持消息信号中断，误开会导致设备失联，不提供；
- **AMD 驱动注册表深度调优**：A 卡用户实机反馈存在副作用，只保留清理类规则。

> 如果你见过其它「必开优化」没出现在 Trim 里，大概率属于上述某类——先查机制、再做实测、最后才动手，是这把工具的取舍标准。

## 十二、日志与反馈

- 所有操作记录在 `%APPDATA%\Trim\logs\`，可在「操作日志」页查看和导出；
- 配置和缓存都在 `%APPDATA%\Trim\` 下（settings.json、paths.json、cleanup、cache 等）；
- 问题或建议欢迎提交issues。
